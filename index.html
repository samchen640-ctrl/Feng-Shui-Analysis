連線方式與 401 故障排查：
• 為什麼手機會出現 401？
  1. CORS Proxy 剝除 Header：許多免費 Proxy 會拔掉 Authorization。建議使用無驗證的 cloudflared 穿透，或使用允許傳遞 Header 的自建 Proxy。
  2. LM-Studio Token 設定：若在 LM-Studio 的 Developer 頁面開啟了 Require Authentication，請確保這裡輸入的是對應產生的 API Token。
  3. Cloudflare Access 阻擋：若使用了 Cloudflare Access 保護網域，請暫時關閉 Access Policy 或將手機 IP 加白。

• 推薦穿透（免 Proxy）：終端機執行
  cloudflared tunnel --url http://localhost:1234
  直接將產生的 https://xxx.trycloudflare.com 填入 API URL，此時 Proxy 欄位留空。
