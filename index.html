📖 為何電腦正常但手機連不上？

1. 手機輸入的隱形空格／全形問題（最常發生）：

從 LINE、WeChat、備忘錄複製金鑰或網址時，經常夾帶「零寬空格（Zero-width space）」或全形符號。本版程式已自動為您清除這些隱形字元。

2. HTTPS 與 HTTP 混合內容封鎖（Mixed Content）：

若網頁是透過 HTTPS 載入，手機瀏覽器會自動擋下對 `http://192.168.x.x` 的請求。最完美的解決方式是使用 Cloudflare 免費穿透：

cloudflared tunnel --url http://localhost:1234

產生 `https://xxx.trycloudflare.com` 後直接填入網址，手機電腦皆可安全連線。

3. LM-Studio 必須允許區網連線：

請在 LM-Studio 的「Developer / Local Server」分頁，勾選 Serve on Local Network (0.0.0.0) 與 Enable CORS，並確認電腦防火牆允許 1234 連接埠。

4. 手機上的 Localhost 迷思：

手機上的 `localhost` 是指手機自己！手機必須填寫電腦在 Wi-Fi 中的區網 IP（例如 `http://192.168.1.100:1234`），且手機與電腦必須連接同一個 Wi-Fi。
